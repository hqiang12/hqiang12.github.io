从零到一，用 Hugo 打造你的个人网站

一起来用世界上最快的网站构建框架搭建个人博客站点吧！
2024年8月30日 · 3 分钟 · 1193 字

本文将介绍在本地搭建 Hugo 并部署到静态托管平台的方法。以下所叙之方法即我在部署本演示站点时所使用的，具有借鉴意义。如果在部署过程中遇到报错或其他困难，可以上网搜索或留言——我看到后会提供力所能及的建议。

在部署 Hugo 之前，需要进行的准备：

  1. 安装 Git 。Git 用于版本控制和代码管理，Linux 和 macOS 系统中一般内置，Windows 用户需要手动安装。安装过程中不需要选择任何多余选项，一直点下一步即可。
  2. 拥有一个 GitHub 账号，用于托管代码文件。
  3. 拥有一个称手的文本编辑器：推荐使用 Visual Studio Code 或者你喜欢的编辑器。
  4. 网络环境良好。为了避免下载文件或上传文件至 GitHub 过程中出现错误，保持网络畅通很有必要。

如果你做好了如下准备，那么恭喜你，你可以进行下一步啦！

下载并安装 Hugo#

在 Hugo 的 Release 页面找到最新版本，选择对应平台的 hugo_extended 压缩包下载并解压。

创建站点#

将下载后的内容放在一个空文件夹中，在当前文件夹上方地址栏输入 cmd，唤起命令行，然后执行：

hugo new site 我的博客
cd 我的博客
hugo server

用浏览器打开 localhost:1313。如果页面显示 “Page not found”，说明此前所有配置都正常无误——站点骨架已经就绪。

配置主题#

Hugo 默认没有主题，需要到主题商店 挑选。本文以 PaperMod 为例，把主题下载并解压至 themes 文件夹中，然后在 hugo.yaml 中输入相关配置。文件各项配置解释如下，用作参考：

baseURL: https://example.com   # 网站的基本 URL，替换为你自己的网站域名
languageCode: zh-cn            # 网站的默认语言代码，zh-cn 指中文简体
theme: PaperMod                # 使用的主题，与 themes 下的文件夹同名
title: 我的博客                # 网站的标题，会显示在浏览器标签上
enableGitInfo: false           # 用 git 提交时间生成"最后更新"字段
hasCJKLanguage: true           # 中文博客开启它，摘要与字数统计才准确

params:
  defaultTheme: auto           # 跟随系统明暗切换，也可固定为 light 或 dark
  ShowReadingTime: true        # 显示预计阅读时间
  ShowWordCount: true          # 显示文章字数
  ShowBreadCrumbs: true        # 显示面包屑导航
  ShowToc: true                # 显示文章目录

markup:
  highlight:
    noClasses: false           # 以 class 输出高亮，方便用 CSS 自定义配色

撰写文章#

在 content/posts/ 文件夹下新建 Markdown 文件，最上方被 --- 包裹的区域是 Front matter，用以指定文章的标题、日期、分类等属性：

---
title: "我的第一篇文章"
date: 2026-01-01
description: "写在文章标题下方的一句话简介"
categories: ["工作台"]
tags: ["Hugo"]
draft: false
---

常用字段：title 标题、date 发布日期、lastmod 最后更新、description 简介、categories 分类、tags 标签、draft 草稿开关。并不是所有字段都要出现，保证有默认属性即可。

顺手验证一下公式渲染：设第 $n$ 个月的文章数为 $a_n$，若每月翻倍，则

$$S_n = a_1 \cdot \frac{2^n - 1}{2 - 1}$$

部署上线#

内容撰写完毕后，执行 hugo 命令即可在 public/ 文件夹生成整站静态文件。推荐将源文件推送到 GitHub 仓库，再交给 Vercel、Cloudflare Pages 或 GitHub Pages 托管，每次推送都会自动重新构建。

End#

一切正常的话，就可以愉快地享用你的个人博客啦！当然，部署完成后还可以进行主题美化、评论区配置等一系列繁杂的操作。不过，瞎折腾也不是没有意义的；或许，搭建博客本身就是意义。
